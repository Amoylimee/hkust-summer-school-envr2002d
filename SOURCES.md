# SOURCES.md

This file records the factual and narrative sources used by the deck. The repository is public, so source provenance must be preserved without publishing private material.

## Source policy

- Prefer primary and authoritative sources for non-trivial factual claims.
- Record the source beside the relevant slide during implementation.
- Do not rely on an AI-generated image as factual evidence.
- Distinguish documentary photographs from illustrative pixel art.
- Do not commit private correspondence, email addresses, file identifiers or confidential attachments.
- When a source file was supplied privately, record a neutral description here and keep the actual file outside the public repository unless Jeremy explicitly approves publication.

## Slide-source convention

For each implemented slide, record sources in this format:

```text

- Claim: source title, organisation, date, URL or private-source description.
- Image: filename, creator/source, licence or “AI-generated illustrative pixel art”, date.
```

Generated images should also be entered in the asset manifest described in `assets/README.md`.
