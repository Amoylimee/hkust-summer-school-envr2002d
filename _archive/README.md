# Archive

This directory preserves superseded presentation implementations and outputs.
Nothing here is part of the active build.

## Contents

- `legacy-html-pptx/` — the former HTML-first implementation, PowerPoint build
  scripts, pixel-art assets and exported Part 1 / Part 2 files.
- `beamer-samples/` — the two six-slide Beamer samples used to select the
  current economics-seminar visual direction.

The active deck is maintained in `src/main.tex` and built with
`scripts/build_beamer.sh`.
