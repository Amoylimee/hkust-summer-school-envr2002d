# Beamer style samples

These files document the visual comparison that preceded the current Beamer
design.

- `output/ENVR2002D_Beamer_Opening_Sample.pdf` — sans-serif sample.
- `output/ENVR2002D_Beamer_Opening_EconStyle.pdf` — economics-seminar sample
  approved as the basis of the active deck.
- `src/beamer_opening_sample.tex` — source for the sans-serif sample.

The approved economics-style source was promoted to `src/main.tex`.
