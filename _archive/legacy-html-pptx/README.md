# Legacy HTML/PPTX implementation

This folder contains the complete presentation system used before the switch
to LaTeX Beamer on 30 July 2026.

It includes:

- the former HTML/CSS sources;
- the former HTML and PowerPoint build scripts;
- the original and generated pixel-art assets;
- the 15-slide Part 1 and 12-slide Part 2 HTML, PDF and PPTX outputs;
- the former Python dependency file.

These files are retained for reference and possible content recovery. They are
not maintained, rebuilt or used by the active presentation workflow.
